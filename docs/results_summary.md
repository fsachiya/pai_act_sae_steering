# 結果と考察のまとめ（2026-10-31 時点）

色キューブ仕分けタスクで ACT を模倣学習し、学習済みの重みは固定したまま、推論時の介入だけでキューブを別の色の箱へ入れられるかを調べた。介入は「色（意図レベル）」「x/y 移動（運動レベル）」「軌道」の3種類で、それぞれ TopK SAE の特徴と DiffMean（平均活性の差ベクトル）で比較した。詳細な数値と経緯は `NOTES.md`、図は `artifacts/figs/`、数値は `artifacts/results/`。

## 1. 設定とベースライン
- **環境**: robosuite 1.5.1 + Panda。キューブは右側 (0.07, −0.15)、箱は左側に 2×2（赤 (0.14, 0.10)、緑 (0.00, 0.10)、青 (0.14, 0.24)、黄 (0.00, 0.24)）。赤→緑は x のみ、赤→青は y のみ（隣）、赤→黄は対角。
- **データ**: スクリプト方策で 400 本（色ごと 100 本、初期状態・デモにノイズ）。採用率 100%。
- **ACT**: 30k step。Temporal Ensembling なし（5 ステップごとに再計画）。**E0 成功率 4色とも 100%**（各 50 エピソード）。
- **SAE**: encoder 4層・decoder 4層の計 8 か所 + color トークン専用の「色の SAE」。R² はすべて 0.97 以上、SAE で置き換えても成功率 100%。encoder の浅い層は死んだ特徴が 10% を超えた（層0: 30%、color 専用: 11〜41%）。

## 2. 主な結果: 介入3種類 × SAE / DiffMean（E1, 12 対 × 20 エピソード）
| 介入 | SAE | DiffMean |
|---|---|---|
| 色（encoder_layer0 の color トークン） | 90%（3トークン共通）/ 94%（色の SAE） | **100%** |
| x/y 移動（decoder_out） | 13% | 16% |
| 軌道（decoder_out） | 14% | 34% |
- 色の介入はどの方向にも効き、エピソードの最初から入れても把持は崩れない（把持率は全条件 100%）。
- 探索の網羅性: 位置（候補の全層）× 強度（5段階）× 特徴数（1〜20）の 166 マス・9960 エピソードで探しても、x/y は最高 17%、軌道は最高 35%。色は encoder_layer0 だけが高く、深い層ほど効かない。
- 色の SAE は特徴 1 個では 0%、5 個以上で 88〜95%（色は複数の特徴にまたがって表現されている）。

## 3. x/y・軌道が効かなかった要因の分析
- **データの偏り**: 運搬中の手先の動きは +y が 80%、−y は 3%。x/y・軌道の介入が成功したのはほぼ +y 方向だけ。
- **引き戻し**: 色の特徴を抑えると元の箱へ戻る率は 14% → 2〜3% に下がるが、到達率は上がらず箱外が増えた。色を抑えるだけではキューブは他の箱へ行かない（置く場所を決められない）。
- **チャンクの直接比較**（行き先の色にしたときのチャンクにどれだけ近づくか）: 色 81〜89%、x/y 20〜33%（行き先方向へは十分動くが、状態によらない一定の押し）、軌道 SAE −1%（行き先を担っていない）、軌道 DiffMean 22%。
- **軌道の特徴は特定できたか**:
  - 行き先の情報は decoder にも線形に ~100% 含まれるが、色ごとに選んだ 20 特徴では 59〜73%、1 特徴では 34〜38%（偶然 25%）しか読めず、少数の特徴にまとまっていない。
  - 因果的に選び直すと（反実仮想の対 + attribution patching）、**decoder_out の約 50 特徴（2048 中）を状態に応じた値に差し替えれば 90% 切り替えられる**。ただし決まった値に固定すると 2〜8%。逆向きの対（a→b と b→a）で同じ特徴が使われ、「箱 c 行き」という記号ではなく「行き先までの残りの移動」のような状態依存の量を表している。
  - 4パターンの違いは関節角度でも内部表現でも「x の行き先 + y の行き先」の足し算でほぼ説明できる（パターン固有の部分は 関節角度 0.6%、decoder 4〜13%）。パターンを4つの独立な記号として持つのは encoder の color トークンだけ（1/3 = 33%）。
- **probing と steering**: 単一特徴では、相関の向きと刺激したときの動きはよく一致する（cos 0.88〜0.99）。ずれていたのは、「+x の特徴」として選んだ特徴が相関の段階からすでに斜めだったこと（1個で x 軸に沿う特徴が無い）。

## 4. x/y 介入の改善
| 条件（評価 seed 100〜119, 12 対 × 20） | 到達率 |
|---|---|
| 従来 SAE（上位3特徴） | 16% |
| DiffMean | 18% |
| 組み合わせで選ぶ（7次元で直交成分を打ち消す） | 32% |
| + 軸ごとに強さを較正 | 52% |
| + 対角は対ごとの強さ・−y は下ろし始めで停止 | **58%** |
| 上に色の抑制を追加 | 36〜48% |
- 1軸の移動は +x 98%、−x 100%、+y 100% まで届くようになった。従来の失敗の多くは「斜めの特徴が足し合わさる」「グリッパーなど他の成分の混入」「軸ごとに必要な強さが違う」ことによる。
- **−y（およびそれを含む対角）はどの補正でも 0%**。方策はいつもの +y 方向の運搬を途中で止めて置くことができず、運搬の高さで止まったまま上限まで終わる。色を抑えても同じ。
- 色の抑制を加えると、+y を含む対角は 100% になるが、1軸の移動は大きく下がる（色が「どこで止まって下ろすか」の基準になっているため）。

## 5. 考察
1. **行き先を自在に変えられるのは、目的（色）の表現への介入だけ**。encoder の color トークンの差し替えは、cross-attention を通じて decoder の全層の計算を変え、今の状態に合った「行き先の箱への計画」をそのまま作らせる。
2. **運動レベル（x/y）の介入は「目的が決める止まる位置」をずらす形でしか働かない**。特徴の選び方と強さを合わせれば、元の箱を通過する方向や同じ距離の方向へは 90〜100% 届くが、目的より手前で置く必要がある方向（−y）には届かない。色を抑えると、届く方向と届かない方向が入れ替わるだけ。
3. **decoder 側に「4パターンの軌道」の記号は無い**。軌道は x・y の成分に分かれ、状態に応じて値が変わる形で表現されている。そのため、決まった値で刺激する介入（SAE の swap、DiffMean）では軌道全体を切り替えられない。
4. **SAE と DiffMean**: 色では DiffMean（100%）が SAE（90〜94%）を上回った。x/y では、SAE の特徴を組み合わせて使うと DiffMean（18%）を大きく上回る（58%）。SAE の利点は、行動の成分ごとに分解して「狙った方向だけに効く組み合わせ」を作れる点にあった。

## 6. 限界
- 色と行き先が常に 1対1 なので、色の特徴が「色の識別」なのか「箱 c 行き」なのかはデータから区別できない。
- gate（介入のタイミング）にはシミュレータの真の状態を使っている。
- 2×2 配置の 4 パターン、Temporal Ensembling なし、辞書 2048・TopK の SAE という条件での結論。配置を変えたり CLT などを使えば、軌道ごとの特徴が現れる可能性はある。
- x/y の補正（較正・対ごとの強さ）は調整用 seed で決め、別の seed で評価したが、方向ごとに調整しているので「汎用の介入」ではない。
